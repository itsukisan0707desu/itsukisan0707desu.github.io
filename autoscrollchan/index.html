⬇ ダウンロード

H.264 MP4 の書き出しには WebCodecs 対応ブラウザ（Chrome / Edge / Safari 16.4+ など）を推奨します。非対応の場合は録画方式（動画の長さ分の時間がかかり、WebMになることがあります）で書き出します。

📝 出勤ツイートをつくる

④ 出勤キャスト（チェックで表示 / 非表示）

左から：出勤チェック / 先頭の絵文字 / 名前 / Xアカウント（任意。@は付けても付けなくてもOK）

CSVで保存 / 読み込み（店名・文章・キャスト全部）

「CSVに保存」で店名・各文章・ハッシュタグ・キャスト（チェック状態込み）を shukkin_settings.csv にまとめて保存します。前に作った出勤ツイート生成ツールのCSVもそのまま読み込めます（UTF-8 / Shift_JIS 対応）。

⑤ 日付

⑥ 文章（おまかせ自動 or 手で編集）

使える置き換え：{店名} {日付}（例 11/20(金)） {人数}（出勤人数）。チェックを外すとその行ごと消えます。

⑦ 生成結果

結果欄は手で直接編集もできます（キャスト・日付・文章を変えると再生成されます）。
